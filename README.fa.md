# دفتر — حساب مشتریان بیمه

برنامهٔ سادهٔ فارسی با تاریخ شمسی، پروندهٔ مشتری، بیمه‌نامه، اقساط و ثبت پرداخت.

**وضعیت فعلی:** برنامه آفلاین کار می‌کند، ولی اطلاعات فقط در همان مرورگر و دستگاه ذخیره می‌شود. همگام‌سازی اینترنتی هنوز پیاده‌سازی نشده است.

## ادامهٔ کار توسط GPT دیگر

ابتدا `AGENTS.md`، سپس `docs/HANDOFF.md` و `VALIDATION.md` را بخوانید. فایل‌های سایت در `dist/` و آزمون‌ها در `tests/` هستند. دستور بررسی: `npm test`.

## انتشار روی GitHub Pages

در تنظیمات مخزن، بخش Pages، منبع انتشار را GitHub Actions انتخاب کنید. گردش‌کار `.github/workflows/pages.yml` پس از قبولی آزمون‌ها، محتوای `dist/` را منتشر می‌کند. لینک سایت را از نتیجهٔ انتشار بردارید.

## انتقال اطلاعات قبلی

دامنهٔ جدید حافظهٔ جداگانه دارد. در سایت قبلی فایل پشتیبان بگیرید و در سایت جدید بازگردانید. بازگردانی، دفتر شخصی فعلی را جایگزین می‌کند؛ ابتدا از اطلاعات موجود پشتیبان بگیرید. فایل مشتریان را داخل مخزن GitHub قرار ندهید.

## تصمیم‌های کاربر

- دسترسی به سایت بدون ورود به ChatGPT.
- تأیید صریح تومان یا ریال؛ بدون تبدیل خودکار.
- طرح Firebase Spark با پرداخت غیرفعال.
- در آینده: ذخیرهٔ محلی آفلاین و ارسال خودکار پس از اتصال، همراه با دسترسی بسیار ساده برای پدر.
